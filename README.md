# Welcome to Callumify 🧠✨

Yes. It's the only Python package (probably) with a **Quote of the Day** function.

Why settle for silent scripts when you could start your day with a dose of wisdom, wit, or weirdness? Callumify is here to remind you that code can be clever *and* charming.

## Features
- `quote_of_the_day()` – because your terminal deserves a pep talk.
- 'grUHHHHHHMble()' - because the terminal wants to GRRRR!
- More coming soon... maybe. If Callum feels like it.
